# 💰 돈, 모을까 불릴까 금융원정대

금융감독원의 금융 교육 보드게임 **"모을까? 불릴까? 금융탐험대"**의 규칙을 바탕으로 초등학생들이 재미있고 쉽게 저축, 주식, 채권 등의 기초 금융 지식을 체득할 수 있도록 재구성한 **교육용 웹 보드게임 애플리케이션**입니다.

---

## 🎮 주요 게임 기능

1. **시작 화면 (Lobby)**
   - 2명 / 3명 / 4명 중 동반 플레이어 인원수 선택
   - 고유 이모지 및 캐릭터 색상(🔴빨강, 🔵파랑, 🟢초록, 🟡노랑)이 부여된 개별 닉네임 기입 지원
2. **실시간 시세 표시판 (Real-time Market Board)**
   - 주식 및 채권 시세 실시간 시계열 반영 (5G ~ 20G 범위 한계 도달 배지 작동)
   - 가격 등락 시 **빨강(상승 📈) / 파랑(하락 📉)** 깜빡임 플래시 시각 이펙트 및 수치 카운트 롤링 애니메이션 제공
3. **경제 뉴스 카드 시스템 (News Deck)**
   - 초등학생 눈높이에 맞춘 아동용 주식/채권 뉴스 총 24종 수록
   - 사용한 뉴스 카드는 덱의 맨 뒤로 밀려나는 **순환 큐 방식** 적용
4. **저축 & 이자지급 시스템**
   - 저축 칸 도착 시 10G씩 은행에 적금할지 선택
   - 이자지급 칸 도착 시 저축 누적액의 **10% 보너스 복리 이자** 수령
5. **금융 O/X 퀴즈 & 이벤트 행운 카드**
   - 저축의 속성, 투자의 위험성 등 핵심 지식 O/X 퀴즈 (정답 시 +5G / 오답 시 -3G)
   - 세뱃돈 보너스 🧧, 스마트폰 게임 폭탄 지출 📱 등 다양한 상황별 행운의 럭키/지출 이벤트 카드 발동
6. **금융 여행 (스페셜 칸)**
   - 저축하기, 이자받기, 행운 카드 드로우 등 자기 주도형 자산 증식 선택 지원
7. **자산 종합 정산 & 시상식 포디움 (Result Page)**
   - 게임 완주 시 보유한 주식 및 채권을 최종 시세로 완전 현금화(Liquidated)
   - 현금 + 저축 + 주식 평가가치 + 채권 평가가치를 합산한 **총 자산 가치(Net Worth)** 랭킹 순위 산출
   - 금/은/동메달(🥇, 🥈, 🥉) 시상대 출력 및 가계부 breakdown 상세 내역 표출

---

## 🛠️ 기술 스택
- **Frontend Core**: HTML5, Vanilla JavaScript (외부 프레임워크나 패키지 없이 순수 웹 컴포넌트 구조 개발)
- **Styling**: Vanilla CSS3 (둥글둥글한 밝고 따뜻한 파스텔 톤 테마, 모바일-데스크톱 반응형 뷰포트 지원)
- **개발 환경**: Node.js 기반의 초경량 로컬 정적 웹 서버 구동

---

## 💿 실행 방법

본 프로젝트는 의존성 라이브러리가 없어 Node.js가 설치되어 있다면 즉시 구동할 수 있습니다.

1. 본 저장소를 클론받거나 소스 파일을 다운로드합니다.
2. 터미널을 열어 프로젝트 루트 디렉토리로 이동합니다.
3. 아래 명령어를 실행하여 로컬 개발 서버를 구동합니다:
   ```bash
   node server.js
   ```
4. 크롬 등 브라우저를 열고 **`http://localhost:3000`** 주소로 접속하면 즉시 게임을 즐기실 수 있습니다!
